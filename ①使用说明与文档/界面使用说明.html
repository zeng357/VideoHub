二、五步快速上手（番剧下载）

1
顶部「站点」下拉选择站点（如 AGE动漫 / 樱花动漫 / 哔哩哔哩）
2
「关键词」栏填剧名——无需复制地址
3
点「加载剧集表」→ 自动搜索并解析全部集数
4
剧集表勾选想要的集 + 「下载设置」选速度档位
5
点「开始下载」→ 逐集完成（B站自动合成音视频为单 mp4）

三、⑤ 下载设置（速度档）

  • 极速(32线程)：HLS 分片 / 直链分段并发最高，速度最快
  • 高速(16线程)：较快，服务器压力较小
  • 标准(6线程)：默认，稳定
  • 平稳(3线程)：服务器弱/风控严时用
顺序重要：先选好速度，再点「开始下载」。直链下载自动探测服务器 Range 支持，不支持时自动回退单线程。

四、⑥ 按钮行

按钮作用
清空状态清空日志与进度显示
加载剧集表解析剧集列表到剧集表（可勾选）
🎲 随机抓取仅「抖音精选」亮起：持续随机抓取精选流，点击后变「停止」，抓取时间与数量由你控制，停止后填入剧集表
开始下载下载勾选的剧集
退出关闭程序

五、抖音精选 · 随机抓取（人控模式）

1
站点选「抖音精选」（搜索方式任意）
2
点「🎲 随机抓取」→ 按钮变「停止」，程序开始持续随机抓取
3
界面实时显示「已抓到 N 个视频（抓取中...）」——想抓多少等多久由你定
4
点「停止」→ 已抓视频全部填入剧集表 → 勾选 → 选速度 → 开始下载
抖音风控严格：连续无数据自动等待重试；直链签名约 6 小时有效，抓到后尽快下载；需要更高清可填浏览器 Cookie。

七、设置页（左侧「设置」）

  • 浏览器：Edge / Chrome 选择
  • 无头模式：勾选后后台运行不弹浏览器窗口
  • Cookie 栏：粘贴浏览器 Cookie（F12 → 网络 → 请求头 Cookie），用于登录站点/高清下载
  • 打开登录页 / 登录完成：程序内登录并自动保存 Cookie

八、常见问题

Q：加载剧集表提示“部分集数未解析到视频源”？
A：已容错：成功集正常交付，失败集跳过并在日志列出，不中断整批；可重新加载重试。
Q：点击下载卡住 / 网页全站打不开？
A：站点被限流（尤其华力站）。程序已内置：弱站 4 线程、每集重试、随机延时 + 真人 UA 模拟。等 10-30 分钟风控解除后再试。
Q：下载后是 .ts 而不是 .mp4？
A：未检测到 ffmpeg。安装 ffmpeg 并加入 PATH，或放到 C:\Program Files\ffmpe\bin\，重启程序。
Q：需要登录/高清的站点？
A：设置页 Cookie 栏粘贴浏览器 Cookie 后重试。
Q：抖音精选抓到 0 个？
A：抖音风控，等 1-2 分钟再点；或填抖音 Cookie 提升稳定性。
Q：出错了看不到原因？
A：日志自动写入 下载日志.txt（程序目录），把内容发出来即可定位。

九、安装与启动

环境：Python 3.8+ / Edge 或 Chrome / ffmpeg（推荐）

安装依赖：pip install -r requirements.txt

启动：双击 一键启动.bat（推荐）；或 python gui.py

提示：新增站点 = 在 sites_data/ 放入插件文件 → 点「刷新」→ 下拉即出现。参考 template_crawler.example.py 模板。
