# 常见问题（FAQ）

本文汇总使用「通用视频下载器」过程中最常见的 15 个问题与解决方法。如果这里没有解决你的问题，请查看 `下载日志.txt`（程序同目录）或阅读《原理说明.md》。

## 一、启动与界面

### 1. 双击启动后弹出一个黑色窗口，瞬间就关闭？
这是典型的启动失败。常见原因与处理：
- **没装 Python**：本工具需要 Python 3.10+。打开命令行执行 `python --version`，若提示"不是内部或外部命令"，请到 python.org 下载安装，安装时务必勾选 **Add Python to PATH**。
- **依赖没装**：在程序目录执行 `pip install -r requirements.txt`。
- **ffmpeg 缺失**：B站音视频合成依赖 ffmpeg。若 `C:\Program Files\ffmpe\bin\ffmpeg.exe` 不存在，请安装 ffmpeg 并修改 `config.py` 里的路径。
- **看日志**：黑窗口是控制台程序，关闭太快看不到报错。改从命令行运行：`python gui.py`，报错会留在窗口里。

### 2. 程序打开了，但界面不是截图里那样？
请确认你启动的是 `一键启动.bat`（或 `python gui.py`），而不是旧的漫画版入口。界面为深色风格：左侧站点导航 + 右侧剧集表 + 下方双进度条。

### 3. 下载的视频保存在哪里？
默认保存到程序目录下的 `下载/` 文件夹，按"站点名/剧名/集数"分目录存放。可以在界面选择保存位置。

## 二、搜索与扫描

### 4. 搜索不到想要的剧集？
- 确认站点选对：不同站点收录范围不同（AGE动漫、樱花动漫、哔哩哔哩、抖音精选）。
- 关键词用**剧名简称或原名**，避免带空格和特殊符号。
- 搜索后请**先点击进入结果页面再扫描**：程序会先定位目标剧集页，再读取该页的剧集列表。
- 站点风控时会返回空结果，稍等几分钟再试（见问题 10）。

### 5. 扫描很慢，要一级一级打开？
- 这是正常防护：程序按"先检测总集数 → 再按集数爬取"的顺序工作，并带随机延时避免触发风控。
- 想快一点：选**极速档**；想稳一点：选**标准/平稳档**。
- 站点服务器弱的（如部分老站）天然慢，属于站点问题，不是程序问题。

### 6. 扫描到的集数比实际多/少？
- 多：站点列表包含 OVA、SP、预告等特别篇，属正常。
- 少：可能是剧集页懒加载，程序已做滚动加载处理；若仍缺失，换"自动扫描"模式或换站点重扫。
- 程序会**先检测总集数**再爬取，防止多爬。

### 7. 搜索结果打开后是乱码或跳回主页？
这是站点搜索链接格式问题。程序内部已按各站点真实路由处理（樱花动漫 `/video-search/...html?wd=`、AGE动漫 `/search?wd=`、华丽装饰 `/vodsearch/...html`）。若仍出现，说明该站点改版，请更新对应爬虫插件（见《③站点扩展与工具》）。

## 三、下载

### 8. 点击"开始下载"后卡住、没有任何反应？
请按顺序排查：
1. 看界面下方的**日志区**是否有输出；没有则看 `下载日志.txt`。
2. 确认已**先选速度档再点下载**（速度档与下载是两个独立步骤）。
3. 代理/VPN 冲突：程序默认直连，若开了代理请关闭或把站点加入代理白名单。
4. 站点临时不可用：程序内置 90 秒无进展看门狗，超时会自动中断并提示，可换源重试。
5. 极速档线程多（32 线程），若被站点限流会变慢，改用标准档（6 线程）。

### 9. 为什么只下载了第一集？
旧版本有该问题（剧集页懒加载只抓到第一集）。请使用当前版本：扫描时会滚动加载完整剧集列表。若仍有问题，勾选剧集后确认**列表里显示全部集数**再下载。

### 10. 下载中途失败/被风控（提示限流、要求登录）？
- 降低速度档：极速 → 高速 → 标准 → 平稳。
- 程序内置**随机延时 3.5~6 秒、4 组 User-Agent 轮换、模拟滚动**等人性化策略，但仍请理性控制频率。
- 目标站点被风控时**连正常登录都会受影响**，请停止使用一段时间（几小时到一天）再试，勿持续高强度爬取。

### 11. B站视频下载后只有画面没有声音 / 文件损坏？
B站是音视频分离的（DASH），程序会调用 ffmpeg 自动合成 mp4。请确认：
- ffmpeg 已安装且 `config.py` 路径正确；
- 程序目录 `下载/` 下有 `视频.mp4` 与 `音频.m4a` 临时文件时，说明合成未完成，手动用 ffmpeg 合并即可：`ffmpeg -i 视频.mp4 -i 音频.m4a -c copy 合成.mp4`；
- 需要登录的番剧请在浏览器登录 B站后，把 Cookie 填入界面"B站 Cookie"栏（Cookie 获取方法见《使用说明.md》）。

### 12. 第一个播放源打不开，能不能自动换第二个？
能。程序支持**多播放源自动切换**：某个播放源解析失败时，会自动尝试下一个源（AGE动漫等站点已实现），并去重保留第一个可用的线路。

### 13. 下载进度条不动 / 下载完没有提示？
- 进度条按"已完成集数/总集数"更新，单集内下载中会显示网速。
- 下载完成后会弹出完成提示。
- 若界面卡死但日志还在写，是站点响应慢导致，等待或换档位重试。

## 四、抖音精选

### 14. 抖音"随机抓取"点了没反应？
- 确认站点选「抖音精选」、地址为 `https://www.douyin.com/jingxuan`。
- 点击"🎲 随机抓取"按钮后按钮会变为"停止"：程序会按你设定的**抓取时长/数量**人控抓取，点"停止"即结束。
- 需要登录的页面请在浏览器先登录抖音（Cookie 自动带入）。
- 抓到的视频为无水印 mp4 直链，保存在 `下载/抖音精选/`。

## 五、其他

### 15. 换了电脑/系统，程序还能用吗？
- Windows 可用；程序为 Python 编写，理论上跨平台，但 ffmpeg 路径、bat 启动脚本需按系统调整。
- 把整个程序目录拷贝即可，站点插件在 `sites_data/` 下，新增站点插件放入后自动注册。
