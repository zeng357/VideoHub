# 使用说明（操作步骤）

> 以主界面从上到下 10 个功能区为序；全文对应图文版《界面使用说明.html》。

## 一、环境要求与启动

| 依赖 | 说明 |
|------|------|
| Python 3.8+ | 推荐 3.10，`pip install -r requirements.txt` |
| Edge / Chrome | 程序自动化浏览器 |
| ffmpeg（推荐） | `C:\Program Files\ffmpe\bin\ffmpeg.exe` 或加入 PATH；HLS 封装、B站合成需要 |

启动：双击 `一键启动.bat`（推荐）或 `python gui.py`。

## 二、界面分区（10 个区块）

| # | 区块 | 用途 |
|---|------|------|
| ① | 站点区（左上） | 下拉选站点、「刷新」重载插件、「打开站点目录」 |
| ② | 搜索方式 | ①自动扫描 / ②站内搜索 / ③直接链接 |
| ③ | 地址 + 关键词 | 按方式填写；选真实站点后**只需填剧名** |
| ④ | 视频设置 | 下载路径（可浏览修改） |
| ⑤ | 下载设置 | 速度档：极速32 / 高速16 / 标准6 / 平稳3 线程 |
| ⑥ | 按钮行 | 清空状态 / 加载剧集表 / 🎲随机抓取 / 开始下载 / 退出 |
| ⑦ | 剧集表 | 勾选下载集（全选/全不选） |
| ⑧ | 获取视频地址进度 | 加载剧集表时的解析进度 |
| ⑨ | 下载进度 | 总进度 / 当前集分片 / 网速 |
| ⑩ | 下载状态 | 日志框（可见 + 落盘 `下载日志.txt`） |

设置页：浏览器选择、无头模式、Cookie 栏（F12→网络→请求头 Cookie）、登录完成保存 Cookie。

## 三、五步上手（皖剧下载）

1. 站点选 **AGE动漫 / 樱花动漫 / 哔哩哔哩**
2. 关键词栏填**剧名**（无需复制估址）
3. 点「**加载剧集表**」→ 自动搜索并解析全部集数
4. 剧集表**勾选** + 「下载设置」选**速度档**
5. 点「**开始下载**」→ 逐集完成（B站自动合成音视频为单 mp4）

## 四、抖音精选 · 🎲 随机抓取（人控）

1. 站点选「抖音精选」→ 点「**🎲 随机抓取**」（按钮变「停止」）
2. 程序持续随机抓取精选流，界面实时显示「已抓到 N 个」
3. **抓取时间与数量由你控制**，随时点「停止」
4. 停止后已抓视频填入剧集表 → 勾选 → 选速度 → 下载

> 抖音风控严：连续无数据自动等待重试；直链签名约 6 小时有效，抓到尽快下载；需要更高清填浏览器 Cookie。

## 五、主页扫描模式（整站批量）

站点选真实站点 + **关键词留空** → 点「加载剧集表」→ 自动扫描主页全部视频名称 → 勾选单个/多个/全部 → 开始下载（逐部自动分析集数并下载全部集，单部失败不影响其他）。

## 六、三种搜索方式

| 方式 | 填什么 | 说明 |
|------|--------|------|
| ① 自动扫描页面 | 地址(+可选关键词) | 打开地址自动扫描；填关键词先站内搜索定位目标页再扫全集；列表页自动滚动触发懒加载 |
| ② 站内搜索下载 | 剧名 + 站点 | 站点插件搜索 → 加载全部剧集表 |
| ③ 直接链接下载 | mp4/m3u8 直链 | 无需浏览器；m3u8 自动选最高清晰度、并发分片、AES 解密、ffmpeg 封装 |

## 七、常见问题

**Q: 加载剧集表提示"部分集数未解析到视频���"？**
A: 已容错：成功集正常交付，失败集跳过并在日志列出，不中断整批；可重新加载重试。

**Q: 点击下载卡住 / 网页全站打不开？**
A: 站点被限流（尤其华力站）。程序已内置：弱站自动降并发（≤4）、每集重试3次、随机延时+真人UA模拟。等 10-30 分钟风控解除后再试。

**Q: 下载后是 .ts 不是 .mp4？**
A: 未检测到 ffmpeg。安装并加入 PATH 后重启。

**Q: 需要登录/高清？**
A: 设置页 Cookie 栏粘贴浏览器 Cookie 后重试。

**Q: 出错了看不到原因？**
A: 日志自动写入程序目录 `下载日志.txt`。
