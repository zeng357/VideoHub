# 通用视频下载器（多站点视频批量下载工具）

一个可运行在 Windows 电脑上的视频下载工具，支持多个视频网站：内置爬虫（A**动漫、B**弹幕视频、Y**动漫、D**短视频、自动扫描）+ 插件化站点扩展——把 `sites_data/` 放入新站点插件即自动注册；支持站内搜索加载剧集表、勾选单集/整部/全部、选择速度档（极速/高速/标准/平稳）一键批量下载；B** 视频自动合成音视频为单个 mp4；D** 短视频支持人控随机抓取。

> 详细说明：《①使用说明与文档/使用说明.md》｜原理见《原理说明.md》｜声明见《免责声明.md》｜问题见《常见问题.md》

# 详细使用教程

## 一、安装运行

### 1. 准备 Python（3.10 或更高）
- 到 python.org 下载安装包；
- 安装时**务必勾选 "Add Python to PATH"**；
- 安装完成后打开命令行，输入 `python --version`，能显示版本号即成功。

### 2. 安装依赖
在程序目录打开命令行，执行：

```bash
pip install -r requirements.txt
```

### 3. 安装 ffmpeg（B** 视频合成必需）
- 从 ffmpeg 官网下载 Windows 版；
- 解压后确保 `C:\Program Files\ffmpe\bin\ffmpeg.exe` 存在（或修改 `config.py` 中路径为你实际的 ffmpeg.exe 位置）。

### 4. 启动程序
- 双击 `一键启动.bat`；或打开命令行执行 `python gui.py`。

> 若双击后黑窗口瞬间关闭，请改用命令行运行 `python gui.py` 查看报错（多为未装 Python 或依赖未装），排查方法见《常见问题.md》第 1 条。

## 二、界面认识

深色界面，分为三块：

| 区域 | 作用 |
|---|---|
| 左侧导航 | 站点选择（A**动漫 / B** / Y**动漫 / D**短视频 / 自动扫描 / 插件站点） |
| 右侧主区 | 地址栏、搜索、剧集表（勾选要下载的集）、速度档选择、下载按钮 |
| 下方状态区 | 双进度条（总进度 + 单集进度）、网速显示、日志输出、下载完成提示 |

## 三、五步上手

### 第 1 步：选择站点
从左侧导航点击一个站点（如「A**动漫」）。已内置的站点无需复制地址；若使用"自动扫描"，可填写站点主页地址。

### 第 2 步：搜索剧集
- 在地址/关键词栏输入**剧名简称或原名**；
- 点击「搜索」，程序会先进入搜索结果，定位到目标剧集的主页（此步骤保证后续扫描的剧集列表正确）。

### 第 3 步：加载剧集表
点击「加载剧情/扫描」，程序会：
- 先检测该剧**总集数**；
- 再按集数读取剧集列表（含滚动加载，避免只拿到第一集）；
- 列表显示后即可勾选。

### 第 4 步：勾选与选速度
- 勾选单集：在剧集表点选；
- 勾选整部/全部：使用"全选"按钮；
- **速度档单独选择**：极速（32 线程，最快）/ 高速 / 标准（6 线程）/ 平稳（最稳，适合弱服务器站点）。**先选好速度，再点下载。**

### 第 5 步：开始下载
点击「开始下载」：
- 底部进度条显示完成进度与网速；
- 下载完成后弹出提示；
- 视频保存在程序目录 `下载/` 下，按"站点/剧名/集数"分目录。

## 四、各站点使用要点

| 站点 | 要点 |
|---|---|
| A**动漫 | 支持搜索 + 多播放源自动切换：第一个播放源解析失败会自动尝试下一个，并去重保留可用线路 |
| B**弹幕视频 | 音视频分离（DASH），程序自动调用 ffmpeg 合成 mp4；需登录的番剧请在浏览器登录后把 Cookie 填入界面"B** Cookie"栏 |
| Y**动漫 | 搜索路由 `/video-search/...html?wd=`，播放 `/video-play/...html`；若遇改版请更新插件 |
| D**短视频 | 精选页随机抓取：点击"🎲 随机抓取"按钮（会变为"停止"），按设定的抓取时长/数量人控抓取，无水印 mp4 直链 |
| 自动扫描 | 填写站点主页，自动列出主页全部视频名称，可勾选单个/多个/全部下载 |
| 插件站点 | 把站点插件放入 `sites_data/`，重启后自动注册到导航 |

## 五、站点插件开发（进阶）

1. 复制 `③站点扩展与工具/sites_data/template_crawler.example.py` 为 `<站点名>_crawler.py`；
2. 实现三个接口：`search_series`（搜索）/ `get_episode_count`（总集数）/ `collect_episode_videos`（按集收集视频地址）；
3. 返回格式：`[{episode_num, title, video_url, video_type, referer}]`；
4. 放入 `sites_data/` 目录，重启程序即自动注册。

## 六、常见问题速览

- **黑窗口秒退**：Python 未装或依赖未装，命令行运行看报错；
- **只下载第一集**：使用新版扫描（已修复懒加载），勾选前确认列表显示全部集数；
- **点击下载卡住**：先选速度档再下载；关闭代理；程序内置 90 秒看门狗会自动中断提示；
- **被站点限流/风控**：改用标准/平稳档，暂停数小时再试；
- **B** 视频没声音**：确认 ffmpeg 已安装且路径正确；
- 完整 15 个问题与解决见《常见问题.md》。
