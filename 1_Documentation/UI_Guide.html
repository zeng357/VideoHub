🎬 VideoToolkit — User Interface Guide

Dark-themed Windows GUI. Three areas:

AreaFunction
Left navigationSite selection: A** Anime / B** Bullet-Screen / Y** Anime / D** Short Video / Auto-Scan / plugin sites
Right main areaKeyword / address bar, Search, Load Episodes, episode table with checkboxes, speed tier selector, Start Download
Bottom status areaDual progress bars (overall + per-episode), speed, live log, completion popup

Quick Start (5 steps)

  1. Choose a site in the left navigation.
  2. Type a title into the keyword bar and click Search — the app finds the target series page.
  3. Click Load Episodes — detects the total count first, then scans the full list.
  4. Check episodes (single / range / all), then choose a speed tier (Turbo / High / Standard / Steady).
  5. Click Start Download — progress bars, log, popup when done. Saved to Download/<site>/<title>/<ep>/.
Keep the console window open — progress is shown there. Closing the console or the main window exits the program.

Speed Tiers

TierThreadsUse when
Turbo32Fast sites, small files, short videos

Standard6Weak servers, long lists
Steady1Rate-limited sites, maximum stability

Choose speed first, then click Download.

Buttons

  • Search — in-site search → locate the series page.
  • Load Episodes / Scan — read total count, then full episode list (auto-scroll).
  • Start Download — batch download checked episodes with progress.
  • 🎲 Random Grab (D** Short Video) — click to start grabbing, click again (Stop) to stop; human-controlled by time/count.

Tips

  • B** videos: DASH audio/video; ffmpeg auto-muxes to mp4. For member-only episodes, paste your browser Cookie into the B** Cookie field.
  • If a site rate-limits you, wait a few hours and use Steady mode.
  • New sites: drop a plugin into sites_data/ and restart — auto-registered.
